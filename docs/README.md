## Documentation Rules

1. Keep documentation written in English.
2. Document architectural decisions and their reasoning.
3. Update relevant documentation when implementation changes.
4. Do not document planned functionality as implemented functionality.
5. Prefer clear examples and explicit technical requirements.
6. Keep application-specific instructions in the relevant application repository.

## Maintenance

The project owner is responsible for reviewing and maintaining these documents.

Documentation must remain consistent with the root IDEA.md, TODO.md, and actual application implementations.
